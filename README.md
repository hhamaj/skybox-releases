# Skybox Launcher releases

Installers of [Skybox Launcher](https://skybox.hamaj.dev), a free Minecraft: Java Edition launcher for Windows,
macOS and Linux. Get the newest version from the [download page](https://skybox.hamaj.dev/download) or from
[Releases](https://github.com/hhamaj/skybox-releases/releases/latest).

This repository only holds the release files; the launcher reads them here to update itself.

[Skybox Launcher](https://skybox.hamaj.dev) için kurulum dosyaları. En yeni sürümü
[indirme sayfasından](https://skybox.hamaj.dev/tr/download) ya da
[Releases](https://github.com/hhamaj/skybox-releases/releases/latest) bölümünden indirebilirsin.
