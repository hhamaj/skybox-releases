Skybox Launcher Flatpak

This is the Flatpak repository of Skybox Launcher. Install it once and flatpak update keeps it up to date.

flatpak install --user https://flatpak.hamaj.dev/skybox.flatpakref

If you installed a downloaded .flatpak file before, remove it first; your instances and worlds stay:

flatpak uninstall dev.hamaj.skybox

Türkçe
